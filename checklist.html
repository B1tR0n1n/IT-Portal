Initial PC setup

Windows 11, offline local account first. Work top to bottom; the boxes are yours to tick while you go.

Open printable sheet

Out of the box

  1. 01Plug in the PC and power it on.
  2. 02Start setup without wifi: press Shift+Fn+F10, then run oobe\bypassnro
    If the command isn't recognized (24H2 and newer), run start ms-cxh:localonly instead and skip to step 4.
  3. 03The PC restarts back into setup.

Offline account setup

  1. 04At "Let's get you connected," choose I don't have internet.
  2. 05Create the user account named for whoever is receiving the PC, in JDoe format.
  3. 06Set the password: •••••• locked
  4. 07Answer all three security questions: •••••• locked
  5. 08Turn off diagnostic data, inking and typing, tailored experiences, and advertising ID.
  6. 09At "Protect this device," skip.

First login

  1. 10Windows builds the account and signs in.
  2. 11Remove unused items from the taskbar.

Network and software

  1. 12Connect to the internet.
  2. 13Install Chrome, Avatara Connect, and Level.
  3. 14Set Chrome as the default browser.
  4. 15Pin Chrome and Avatara Connect to the taskbar.

Identify and record

  1. 16Rename the PC to its asset tag.
  2. 17Add the MAC address, serial, asset number, and assigned user to the spreadsheet.

Accounts and permissions

  1. 18Create a separate local admin account — name •••••• locked, password •••••• locked, then change it to an Administrator account.
  2. 19Sign out of the user account, sign in as the admin account, and remove admin rights from the user account.
  3. 20Sign out and restart the computer.

On the printable copy

The sheet opens in a new tab with fill-in fields for asset tag, serial, MAC and user. With the vault unlocked, the provisioning wizard can hand you the same sheet with those fields already filled and the credentials substituted.
