What this protects, and what it doesn't

Each document is encrypted with AES-GCM under a 256-bit key derived from your passphrase by PBKDF2-SHA256 at the vault's iteration count. The bytes published to GitHub Pages are ciphertext, so the documents are genuinely absent from the public site rather than merely unlinked — a direct URL returns an encrypted blob and nothing else.

It does not make the site private, and it does not survive a weak passphrase. Anyone may download the ciphertext and attack it offline for as long as they like. The authenticated GCM tag means a tampered file is rejected outright rather than decrypting to garbage.

Every file produced here is verified before it is offered: the builder decrypts what it just encrypted and compares it byte for byte against the original. A file that fails that check is never downloaded.
